# Changelog

## [1.0.0] - 2026-03-24
### Added
- Initial release of KKR.ObjectDetector extension
- YOLOv8 real-time object detection via Camera Prim
- Viewport bounding box overlay using SceneView + NDC coordinates
- Single-shot and auto-detect modes with configurable interval
- Confidence threshold slider and model path configuration
- Detection results panel with class counts and colored entries
