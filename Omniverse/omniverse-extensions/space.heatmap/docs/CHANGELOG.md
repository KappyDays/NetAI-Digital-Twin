# Changelog

## [1.0.0] - 2026-03-24
### Added
- Initial release of KKR.SpaceHeatmap extension
- Real-time congestion heatmap overlay on Isaac Sim viewport
- Green-Yellow-Red gradient based on Iceberg Lakehouse congestion data
- Auto-refresh with configurable interval (5-60 seconds)
- Grid resolution control (10x10, 20x20, 50x50)
- Opacity and visibility toggles
- Per-space congestion summary with drill-down detail
- Demo data fallback when API is unreachable
