# KKR.PhysicsSim

Physics simulation with autonomous agents (robot, humanoid, person) patrolling waypoints in a room environment with real-time dashboard monitoring.

## Features

- Auto-generate room environment (floor + walls + ceiling) with physics colliders
- Spawn 3 agents: Robot (Jetbot), Humanoid (H1), Person (Capsule)
- Waypoint-based patrol with cyclic routes
- Real-time dashboard: position, speed, waypoint, progress, collisions
- Nucleus asset loading with primitive fallback for offline use
